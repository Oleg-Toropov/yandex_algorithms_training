<p>D. Правильная последовательность</p>
<p>Правильной скобочной последовательностью назовём последовательность, состоящую из символов "(", ")", "[", "]", "{", "}" и обладающую
следующими свойствами:</p>
<p>1. Пустая последовательность является правильной скобочной последовательностью</p>
<p>2. Если S - правильная скобочная последовательность, то (S), [S] и {S} также правильные скобочные последовательности</p>
<p>3. Если А и В правильные скобочные последовательности, то AВ (к содержимому последовательности А приписано содержимое
последовательности В) также правильная скобочная последовательность</p>
<p>Например, последовательности [](), [{()}]() - правильные, а [}, ([)] - нет.</p>
<p>В скобочной последовательности длины N некоторые символы стерлись (обозначим из как "?"). Определите количество способов
поставить на место "?" какую-либо скобку, чтобы последовательность стала правильной скобочной последовательностью. Так как это
количество может быть очень большим, требуется вывести его по модулю 10<sup>9</sup> + 7 (остаток от деления количества на 10<sup>9</sup> + 7).</p>

<h2>Формат ввода</h2>
<p>В первой строке вводится чётное число N (1 ≤ N ≤ 200) - длина последовательности.</p>
<p>Во второй строке вводится последовательность, состоящая из символов"(", ")", "[", "]", "{", "}" и "?".</p>

<h2>Формат вывода</h2>
<p>Выведите одно число - количество способов заменить знаки "?" на скобки, чтобы последовательность стала правильной скобочной
последовательностью, по модулю 10<sup>9</sup> + 7.</p>

<h2>Примечания</h2>
<p>В первом примере нет знаков вопроса, но последовательность является правильной, поэтому существует единственный способ замены.</p>
<p>Во втором примере возможны следующие замены ({([()])}), ({}[()])(), ({}[([])]).</p>
<p>В третьем примере нет ни одного способа получить правильную скобочную последовательность.</p>
